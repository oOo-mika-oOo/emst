# EMST

Base du futur site de l’EMST, en React et Vite.

## Développement

Avec Node.js 22.12 ou supérieur (Node 24 recommandé) :

```sh
npm ci
npm run dev
```

La page principale se trouve dans `src/main.jsx`, les styles dans `src/style.css`.

## Production

```sh
npm run build
npm run preview
```

Les fichiers statiques à déployer sont générés dans `dist/`.
